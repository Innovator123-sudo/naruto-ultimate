How it matches sharingan.py:
Detection → model(frame, imgsz=640) with confidence > 0.5 → web uses cv.CascadeClassifier.detectMultiScale() (cv2 eye cascade, same threshold). Overlay → cv2.resize(current_sharingan, (scaled_width, scaled_height)) + alpha*0.7 + per-pixel blend → web does canvas.globalAlpha=0.7 + drawImage centered. Blink → consecutive_closed_frames >= 3 + cooldown 0.5s → identical. Rotation → cv2.getRotationMatrix2D + warpAffine @ 720°/2.4s → web ctx.rotate(angle). Audio → pygame.mixer.music → web new Audio().play().
Tip: Blink firmly (close ~200 ms) to trigger. Allow 0.5 s between blinks. Press “Next” to simulate blink without camera.
